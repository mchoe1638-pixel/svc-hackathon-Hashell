## 공동 결정 (합의된 것만)
- 총무는 Android 앱(Capacitor, Vercel 운영 주소를 여는 셸), 동행은 링크로 모바일 웹. 화면 코드는 하나
- 방 만들기는 앱에서만. 총무는 끝까지 앱으로만 사용 (웹과 익명 세션이 따로라 총무 권한이 안 따라감)
- 참여: 이름 고르기 또는 새 이름 추가(OPEN일 때만). 한 이름에 한 기기
- 지출 수정·삭제는 올린 사람·총무만, version 불일치 409. 체크는 기본 전원, 본인만 해제(총무는 대신 가능)
- 정산 확정(SETTLED) 후 쓰기 423, 받는 사람만 '받았어요', 총무만 확정 해제
- 영수증 이미지 저장 안 함. 환율은 현금=방 생성 시 입력, 카드=수출입은행 TTS+수수료(추정 배지)
- 브랜치는 `main`·`backend`(최명규)·`design`(이승화) 세 개만. 각자 자기 브랜치에서 작업하고 세션 끝마다 커밋 하나(메시지에 슬라이스 이름). 슬라이스가 끝나고 vitest·tsc가 통과하면 내 브랜치를 `main`에 병합 (PR·승인 없음). 상대가 병합하면 바로 `main`을 내 브랜치로 받아온다 (공동 계약 변경 직후엔 필수). `main`은 앱이 여는 운영 주소라 병합 후 앱 확인. 미리보기는 내 브랜치 Push 주소, 스크린샷은 메신저로 공유

**2. 상태 전이와 오류 코드**
- OPEN ↔ LOCKED는 초대 링크 열고 닫기다. LOCKED가 막는 건 새 멤버 참여뿐이고 지출·체크는 양쪽 다 된다. 잠금·열기는 총무만(403 `NOT_ORGANIZER`), 이미 그 상태면 성공(멱등), SETTLED면 423 `TRIP_SETTLED`.
- 정산 확정: 총무만, OPEN·LOCKED 어디서나, 이미 SETTLED면 423 `TRIP_SETTLED`. 확정 해제: 총무만, SETTLED → LOCKED, `transfers` 전부 삭제, SETTLED가 아니면 409 `NOT_SETTLED`.
- 받았어요: 받는 본인만(총무도 예외 없음), 아니면 403 `NOT_RECEIVER`. 송금이 없거나 그 여행의 멤버가 아니면 404 `TRANSFER_NOT_FOUND`(둘을 구분하지 않는다), 이미 눌렀으면 처음 시각 그대로 성공. 송금은 SETTLED일 때만 있어서 상태는 따로 보지 않는다.
- 423은 `TRIP_SETTLED`·`JOIN_CLOSED` 두 뜻, 409는 `NAME_TAKEN`·`TRIP_FULL` 두 뜻이다 → 화면은 `status`가 아니라 `error.code`로 가른다.

**5. 정해 둔 것·알아낸 것**
- 품목 태그 값은 `'highball'` (DB CHECK·프롬프트·zod·`ITEM_TAGS`). 시안의 `'hb'`는 시안 전용이다.
- **실제 데이터에서는 맥주·하이볼·차 잔 수가 항상 0이다.** 계약 `ExpenseItem`에 `tag`가 없고, 저장 경로(`create_expense`·`update_expense`·`save_expense_children`)도 `tag`를 안 써서 `items.tag`는 항상 null이다. 그래서 3번째 장은 실제로는 늘 "맥주 0잔" 분기로 나온다. 풀려면 계약 변경 + 저장 마이그레이션이 필요한데 이번 지시가 마이그레이션 금지라 **6번의 변경안만 보여주고 멈춘다.** (사람) 확인용 읽기 쿼리: `select tag, count(*) from public.items group by tag;` — null뿐이면 위 설명대로 (2-1 마이그레이션 `20261103150000` 미적용이면 컬럼이 없다는 오류가 난다).
- 하루 평균 = 총액 ÷ 일수, 일수 = 종료일−시작일+1. 시작·종료 중 하나라도 null이면 평균을 생략하고 "N박 M일"·가장 비싼 한 끼의 날짜 라벨(`spentOn`)도 같이 생략한다 (v4 마이그레이션 `20261104100000`이 적용돼 날짜가 채워져야 값이 생긴다). 반올림은 시안 `rd`와 같은 half-up `floor((2a+b)/(2b))`. 금액은 정수만.
- 색: hex는 `src/data/destinations.ts`에만 두고 화면은 `.wr`에 CSS 변수로 주입한다 (시안은 `--accent`·`--glow`·`--night`·`--foam`(=목적지 paper)을 있는 색만 inline으로 설정). 실제 앱 변수는 `--trip-accent`·`--glow`·`--night`·`--foam`·`--paper`·`--brand`·`--butter` 등이라 accent→`--trip-accent`가 맞는지 `globals.css`에서 확인. 캔버스는 CSS 변수를 못 읽으므로 `story-image.ts`의 `cssVar()`로 읽고 목적지 색은 `destinations.ts`에서 직접 쓴다.
- `detect(title)`는 소문자 부분 문자열 일치, 못 찾으면 기본 city 세트. 오사카 `match`에 "일본"이 있어 "일본 여행"도 오사카로 잡힌다 (시안 그대로). 정함(단위 2): 기본 세트의 `name`·`title`은 시안에서 여행 입력값(`T.place`·`T.title`)을 썼는데 실제 앱에는 그 필드가 없다 → `detect()`가 기본 세트의 `name`을 `trips.title`로 채워 돌려주고(제목이 비면 '여행'), `title`(마지막 장 "우리 이름은")은 고정 문구 '맛집 정복대'로 했다 (문구는 바꿔도 됨, `src/data/destinations.ts` 한 줄).
- 스토리 공유(아이폰): `navigator.share`는 누른 순간에만 되므로 6장 PNG `File`을 미리 만들어 두고 클릭 핸들러에서 `await` 없이 `navigator.canShare({files})` 확인 후 부른다. AbortError는 조용히 끝, 안 되면 `<a download>`+길게 눌러 저장 안내. 그림은 전부 `new Image()`로 미리 불러 `onload`/`onerror`를 기다리고, 실패한 그림은 건너뛰고 나머지는 그린다. 경로는 `/art/{file}`로 통일 (`/_blob/`은 시안 전용).
- 소유권: `public/`·`app/**/page.tsx`·`src/components/`·`src/i18n/`·`app/globals.css`는 디자인(이승화) 영역이지만 이번 지시가 직접 요청해서 진행한다 → **끝에 건드린 디자인 파일을 이승화에게 알릴 것.** CLAUDE.md의 `lib/tripStats.ts`는 지시·기존 파일이 `src/core/tripStats.ts`라 그쪽을 따른다.
